02 · Understand new vocabulary

Group Learn — From HTML Information to CSS Appearance

What is an HTML attribute? The element name (div, h1 or p) tells the browser what kind of element it is. An attribute adds information inside the opening tag. Most HTML elements can use common attributes such as class and id. Their order does not determine their meaning.

<div class="panel" id="food" data-testid="red">Food Donations</div>

Connect the hallway to HTML: The three rooms labelled Science share a group label, just as three elements can share class="science". But Room 102 has only one location, just as id="room102" identifies one specific element. The subject label is not unique; the room number is. These names are values chosen by the person building the page. HTML defines what the attribute names class and id mean.

Which parts are built in? HTML defines the words class and id. We choose the values panel and food. A class is a reusable group label that multiple elements can share. An id should be unique to one element on the page. Neither automatically changes the element's appearance.

Can I invent attributes? Yes, the HTML standard gives us custom data-* attributes. data-testid="red" is a label that iCEV's automated tester looks for. It does not make the section red. If the test expects red, replacing it with donkey could fail the test even when the colors look correct. You can choose your own data values in other projects, but follow an assignment's exact required values.

How does CSS find its target? A CSS rule has a selector before the braces and style declarations inside. A period means a class; a hash mark means an ID. The browser then applies the styles to the matching elements.

.panel { color: white; background-color: blue; }
#food { border: 3px solid gold; }

Every element with class="panel" gets blue background and white text from the first rule; only id="food" gets the gold border from the second. The punctuation in CSS is not part of the HTML attribute value.
