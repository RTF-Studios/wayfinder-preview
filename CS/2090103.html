Learn 1 · Read HTML before styling it

You already know that HTML puts headings and paragraphs on a webpage. Today we add a container and give it names so CSS can find it. Read each piece before you put them together.

1. What does a <div> do?

<div>
  Welcome
</div>

<div> starts a container: an invisible box that groups content. </div> ends it. The browser displays the word Welcome. The container itself does not add a colored background.

Welcome (dashed outline shows the invisible container)

Try it: Point to the opening tag, the text inside, and the closing tag.

2. What do class and id mean?

<div class="card" id="featured">
  Welcome
</div>

A tag such as div says what kind of element it is. An attribute is extra information written inside the opening tag. Here, class="card" gives the element a group name. Many elements can share the same class. id="featured" gives this element a unique name; that id should belong to just one element on the page.

These names do not change the appearance on their own. Think of class as a team name and id as a name tag for one player.

Try it: If two boxes both need the same style, would you give them the same class or the same id?

3. What does data-testid="green" do?

<div data-testid="green">
  Welcome
</div>

data-testid is another HTML attribute. It puts a testing label on the element so the iCEV checker can find the correct box and test your work. The word green is only the label chosen for that test. It does not turn the box green. The iCEV challenge asks you to keep these labels exactly as given so the checker can recognize the boxes.

Try it: Does changing a testing label by itself change the background color? No—styling happens in CSS.

4. How does CSS find the right element?

CSS means Cascading Style Sheets. HTML puts the content on the page; CSS changes how it looks. The part before { is the selector: it tells the browser which element to find. The part inside { } gives the styling instructions.

.card {
  color: white;
}
#featured {
  background-color: navy;
}

The dot (.) says “find elements with this class.” The hash (#) says “find the element with this id.” color changes the text color; background-color changes the background. The colon separates the property from its value, and the semicolon ends the instruction.

These are CSS rules, not functions. Both rules above match the same container because it has both names.

5. Put the pieces together

<div class="card" id="featured"
     data-testid="green">
  Welcome
</div>

HTML gives us the content, shared class name, unique id, and iCEV testing label. The two CSS rules above make the result look like this:

Welcome

The letters are white because of .card. The background is navy because of #featured. The testing label does not affect either color.
