Open the file in the installed TurboWarp editor: File → Load from your computer. Save your own copy.

The 45-minute challenge

  1. 5 min — Explore: Play the starter. Find the player code, falling-object code, and the Score, Lives, and Speed variables.
  2. 10 min — Remix: Change the player, at least one falling object, and the backdrop so the game feels like your world.
  3. 20 min — Code: Make the game better. Add at least one feature that changes how it plays. Pick from the menu below, or invent your own.
  4. 5 min — Partner playtest: Let someone play. Ask what worked and what was confusing. Fix one issue.
  5. 5 min — Save: Test one last time and save the final .sb3 project to your computer.
Minimum finish line: custom artwork + one working code feature + a partner test + saved game. More features are a bonus, not a requirement.

Choose your coding upgrade

  • Level 2: When Score > 9, set Speed to 6. Test whether the objects really move faster.
  • Bonus points: Make one falling object give more points than the others.
  • Sound feedback: Play one sound when you catch an object and a different sound when you miss.
  • New challenge: Make one object harmful, or add a new rule for losing lives.
  • Your idea: Add a feature you can explain and demonstrate.

Need a starting point? Try Level 2. In the Player's green-flag forever loop, add: if Score > 9 then set Speed to 6. Check the Speed variable when the score reaches ten.

Before you leave

Show your partner the change you coded. Tell them, “I changed ___, because ___.” Then listen to one suggestion and improve something.
