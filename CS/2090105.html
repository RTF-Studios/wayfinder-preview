Final CSS reference — use with your existing Day 4 HTML

Keep the existing three HTML panels, the exact data-testid values red, green, blue, and their visible text. In your styles.css, use these rules for the .parent container and .child panels. Do not replace unrelated starter code.

.parent { display:flex; flex-wrap:wrap; gap:0; }
.child { box-sizing:border-box; display:flex;
  align-items:center; justify-content:center;
  height:100px; flex:1 1 100%; padding:0; }
@media (min-width:600px) {
  [data-testid="red"], [data-testid="green"] { flex-basis:50%; }
  [data-testid="blue"] { flex-basis:100%; }
}
