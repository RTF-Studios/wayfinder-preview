02 · Learn from examples

Group Learn

Yesterday we learned that HTML gives the sections identity and a Flexbox parent arranges them. Today the content stays the same while the layout responds to the screen.

The viewport is the space visible in the browser. A media query applies CSS rules only when a screen condition matches. The breakpoint is the threshold. iCEV specifies 600 pixels for this challenge; this is a project requirement, not a universal rule for every site.

.row { display: flex; gap: 12px; }
.panel { flex: 1; padding: 16px; }
@media (max-width: 599px) {
 .row { flex-direction: column; }
}

At 599px the boxes stack in a column. At 600px and wider they remain side by side. The HTML, content and data-testid values do not change. The CSS controls the view. A webpage can be correct for the human viewer and fail a tester if the exact width rule is wrong.
