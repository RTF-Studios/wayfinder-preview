Final Showcase — three panels, two responsive layouts

Today's goal: Read the two complete files below, understand what each section does, copy them into the corresponding files of your assigned iCEV CSS Three-Panel Layout challenge, run its checks, write Your Notes, and select Submit Solution. Keep the exact data-testid names and the visible words Red, Green, Blue: iCEV tests them.

1. Complete HTML — index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Three-Panel Layout</title>
  <link rel="stylesheet" href="src/styles.css">
</head>
<body>
  <div class="parent">
    <div class="child" data-testid="red">Red</div>
    <div class="child" data-testid="green">Green</div>
    <div class="child" data-testid="blue">Blue</div>
  </div>
</body>
</html>

Read the HTML: <!DOCTYPE html> declares an HTML document. <html lang="en"> identifies the page language. The <head> provides the character set, mobile-friendly viewport, page title, and the stylesheet link. The stylesheet path must be exactly src/styles.css because that's the CSS file in the assigned challenge. The <body> contains one parent container with exactly three child panels. Each panel's data-testid identifies it for iCEV's automated tests; its text is what visitors actually see. The HTML structure and these identifiers do not change between mobile and desktop layouts.

Checkpoint: All three boxes exist in this order: Red, Green, Blue. Confirm all opening and closing tags match; do not rename, delete, or duplicate a data-testid.

2. Complete CSS — src/styles.css

body {
  margin: 0;
  background-color: white;
}


.parent {
  display: flex;
  flex-wrap: wrap;
  gap: 0;
}


.child {
  box-sizing: border-box;
  flex: 1 1 100%;
  height: 100px;
  padding: 0;
  display: flex;
  align-items: center;
  justify-content: center;
}


@media (min-width: 600px) {
  .child {
    flex-basis: 0;
  }
}


[data-testid="red"] {
  background-color: red;
  color: white;
}


[data-testid="green"] {
  background-color: green;
  color: white;
}


[data-testid="blue"] {
  background-color: blue;
  color: white;
}

Read the CSS: body sets a white page background and removes the browser's default margin, so panels can meet the viewport edges. .parent creates a flexible row and allows wrapping without gaps. .child makes border and padding count inside each box's size, gives every panel an exact 100px height, and uses a preferred width of 100% below the breakpoint. Inner Flexbox alignment centers each color name horizontally and vertically.

The breakpoint makes the switch: @media (min-width: 600px) activates when the viewport is 600px or wider. There, each child's flex-basis: 0 combines with flex: 1 1 100% to divide available width equally into three side-by-side columns. Below 600px the default 100% basis makes three full-width stacked rows. The final three selectors restore red, green, and blue backgrounds with readable white labels.

Check before submitting: At 375px and 599px, Red, Green and Blue appear as three stacked rows. At 600px and 900px, all three appear side by side in a single row. Every box stays exactly 100px high. There must never be a red-and-green row with blue below it on a wide screen.

In iCEV: Paste HTML into index.html and CSS into src/styles.css. Use Run Output, inspect the two layout states, and run the activity's tests. If something fails, check the stylesheet path, closing tags, exact test IDs, the 600px boundary and any leftover conflicting starter CSS. In Your Notes, explain: “I kept three HTML panels and used Flexbox. At narrow widths each panel uses the full row. A 600px media query changes them to three equal columns. I checked both widths and kept the heights at 100px.” Finally select Submit Solution (or Ctrl+Enter). Do not claim passing tests without running them.
