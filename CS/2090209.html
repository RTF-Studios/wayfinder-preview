Audience
The intended visitors and their needs.
Site map
A plan for organizing page information.
Semantic HTML
Elements communicate the purpose of content.
Relative link
A path interpreted from the current file’s location.
Accessible interface
People can understand and operate its controls.
Privacy
Personal information is protected; a classroom demonstration must be truthful.
Responsive CSS
Layout adapts to available screen space while content remains available.
Quality assurance
Repeatable checks of expected behavior and observable results.
