02 · Explore a design system

Group Learn — What Does Flexbox Actually Do?

Yesterday: HTML attributes gave elements names, and CSS selectors found those names to change style. Today we ask a new question: how does a website organize several related elements without moving each box by hand?

Flexbox is a CSS layout system. Its name comes from flexible boxes. You set display:flex on the parent container, and the browser arranges its children in a row by default. The children do not need their own display:flex to line up. This distinction is why a selector must target the correct element.

<div class="panels">
 <div class="panel" data-testid="red">Food</div>
 <div class="panel" data-testid="green">Volunteer</div>
 <div class="panel" data-testid="blue">Recipes</div>
</div>

.panels { display: flex; gap: 12px; }
.panel { flex: 1; padding: 16px; }

Who controls what? .panels controls the group and its layout. .panel controls shared styling and the children's ability to use available space. gap creates consistent distance between boxes. flex:1 lets three panels share available room rather than giving each a rigid pixel width.

The boxes are siblings; their common parent distributes the horizontal space.

What happens if you use the wrong selector? If you apply display:flex to .panel instead of .panels, it affects the arrangement inside each panel, not the arrangement of the three panels as a group. The labels data-testid="red", green, and blue still matter to iCEV’s testing program even though they don't style or arrange the boxes.

index.html

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="utf-8">
        <link rel="stylesheet" href="src/styles.css">
    </head>
  
    <body>
      <div class="parent">
        <section class="child" data-testid="red">Red</section>
        <section class="child" data-testid="green">Green</section>
        <section class="child" data-testid="blue">Blue</section>
      </div>
    </body>
</html>

src/styles.css

body {
  background-color: white;
}

/* PARENT: arranges the three child panels */
.parent {
  display: flex;
  flex-wrap: wrap;
  gap: 0px;
}

/* CHILDREN: share space and interior padding */
.child {
  flex: 1;
  padding: 40px;
}

/* Keep HTML data-testid labels unchanged. */
[data-testid="red"] {
  background-color: red;
  color: white;
}
[data-testid="green"] {
  background-color: green;
  color: white;
}
[data-testid="blue"] {
  background-color: blue;
  color: white;
}
03 · Understand the ideas

Read, Discuss and Check

Read: Flexbox arranges items inside a container. display:flex creates a flexible row by default, gap separates items, and flex-wrap lets items move to a new row when space runs out. Readable layouts change with screen width rather than forcing a visitor to scroll sideways.

Think and talk: Three serving trays fit on a long table but not a small desk. Which layout change would help?

Vocabulary check: Match container, item, gap and wrap to a description of where a tray sits and how it moves.

Choose: When a narrow screen makes three columns unreadable, should the design A) shrink text to 3px B) allow panels to wrap or stack C) hide all content? Explain why.

Comprehension: Describe the difference between horizontal alignment and responsive layout in words. No coding product today.
