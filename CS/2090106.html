Quick Study Notes

Use these notes if you forget a word. They remind you of big ideas, not the answers.

Words to remember

Algorithm
Steps to complete a task.
Variable
A named place for information, like a score.
Condition
A yes-or-no check that helps a program choose what happens.
Loop
Code that runs again and again.
Debugging
Finding and fixing a problem.
Binary
Using the digits 0 and 1 to represent data.
Hardware
The physical computer parts.
Software
The programs that run on a computer.
HTML
Organizes headings, text, links, and other web content.
CSS
Changes colors, spacing, and layout.
