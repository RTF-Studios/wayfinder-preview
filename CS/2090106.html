Your Web Design Field Notes

This is a partially open-notes assessment. You may scroll back to these notes while answering. They remind you of the vocabulary and big ideas from Part 1. The test will still ask you to apply them to new situations, compare choices, and explain decisions in your own words.

Vocabulary to remember

HTML
The page's structure and meaningful content: elements, headings, paragraphs, and sections.
Element & tag
An element represents part of a page; tags mark where many elements start and finish.
Attribute
Extra information inside an opening HTML tag, such as a class or testing identifier.
CSS
Rules for presentation, including color, spacing, fonts, size, and layout.
Selector & declaration
A selector targets elements; declarations describe the properties and values to apply.
Box model
The way a browser accounts for content, padding, borders, and margins around a box.
Flexbox
A CSS layout system that distributes and aligns items inside a parent container.
Viewport & breakpoint
The available screen viewing area and a chosen size where design rules may change.
Media query
A conditional CSS rule used to adapt the design to device or viewport conditions.
Test identifier
A stable name that helps software locate a particular HTML element during checking.

Think like a designer

Structure → Style → Layout → Adapt → Test. First make the content meaningful, then make it readable, arrange it for the viewer, adjust for different screen sizes, and check both what people see and what the project requirements expect.

Ask yourself: What belongs in HTML? What belongs in CSS? Who is the audience? How could I check whether my proposed fix actually works?
