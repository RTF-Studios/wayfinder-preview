Learn 1

Flexbox works on the parent. The CSS .panels { display:flex; gap:12px; } tells a container to arrange its children in a row. Putting display:flex on each child instead changes the layout inside the child—not the three-panel arrangement. Watch what happens to the siblings when you move the rule to the parent.

Learn 2

Three fixed panels each 300px wide plus two 20px gaps need 940px, so they cannot fit into a 750px space without shrinking or overflowing. A flexible pattern is .panel { flex:1 1 0%; min-width:0; }. Test in the wide preview. Compare how much room each panel gets before and after replacing fixed widths.
