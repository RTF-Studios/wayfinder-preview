Learn 1

CSS controls presentation, not the HTML meaning. A CSS rule begins with a selector, then pairs each property with a value. Compare .panel { background-color: blue; color: white; } with #panel: the first matches a class, the second an id. The iCEV verifier searches data-testid, which is neither selector. Predict the color of all three panels before you run the code.

Learn 2

A box has content, padding, border and margin. With box-sizing: content-box, width 200px plus 20px padding on both sides occupies 240px before borders. With border-box, the outside width stays 200px. Compare a correct and incorrect panel in your preview, and explain why low-contrast text is harder to use.
