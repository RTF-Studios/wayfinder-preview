CSS Styling and Selectors

Responsive Three-Panel iCEV Coding Challenge

CS Library
Learning Target

We will style HTML using CSS colors and selectors so that visitors can read clearly separated sections.

Priority TEKS: §127.672(d)(2)(C) • Supporting: §127.672(d)(2)(D)

Warm-Up

Compare a wide three-panel row with a narrow stacked view. Predict which HTML or CSS rule causes the difference. Use your iCEV editor and current code to test your prediction.

Learn 1

CSS rule: .panel { background-color:blue; color:white; }. A period selects a class; # selects an ID. data-testid is a test attribute, not a class.

Perform 1

  1. In iCEV preserve the three red/green/blue data-testid values
  2. Add class="panel" to each and use .panel rules to set height, padding and box sizing

Learn 2

Box model: content, padding, border, margin. box-sizing:border-box includes padding and border inside declared width. Use enough text/background contrast.

Perform 2

  1. Style the panels with correct backgrounds and readable text
  2. Preview, identify a mismatch and correct it; do not submit unfinished final challenge
