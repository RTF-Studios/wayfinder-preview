Learn 1

A responsive breakpoint tells the browser when to switch layout rules. First make the wide view a horizontal Flexbox row. Then write @media (max-width:599px) { .panels { flex-direction:column; } }. Why 599 instead of 600? Because the challenge expects stacking below 600px, while exactly 600px remains wide.

Learn 2

Do not trust one preview width. At 390px the panels should stack vertically; at 599px they should still stack. At 600px and 900px they should form a row. If a narrow page scrolls sideways, inspect fixed widths, large images, long unbroken words and missing min-width:0.
