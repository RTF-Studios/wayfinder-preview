Warm-Up · An invisible detail in an opening tag

Read the code on the left and imagine what a visitor sees on the right. Extra information in an opening tag is called an attribute.

Developer writes
<p title="Community pantry hours">Food is available.</p>

The attribute title="Community pantry hours" has a name and a quoted value.

Visitor sees

Food is available.

The extra attribute is not a second visible paragraph.

Why software needs labels

As websites grew beyond simple linked documents, developers needed ways to describe particular parts of a webpage. HTML attributes can supply extra information or identifiers for browsers, accessibility tools and software tests. Today you'll identify those attributes without confusing them with the text visitors read.

Learn 1 · Containers with meaning

Elements can be nested: one outer <section> can contain a second-level heading <h2> and a paragraph <p>. The closing section tag comes after its children.

Meaningful structure
<section>
  <h2>Volunteer Hours</h2>
  <p>Ask the front desk about shifts.</p>
</section>

<section> groups a meaningful topic. A general <div> groups content without conveying a specific topic.

One more attribute before you build: data-testid is a name a testing tool can search for. For example, <section data-testid="example-section"> identifies a section in source code but does not display the identifier or add visual styling. The actual three values are red, green and blue. Copy the matching identifier for each box exactly.

Visitor sees

Volunteer Hours

Ask the front desk about shifts.

The section element does not automatically create a visible border, color or row of panels. CSS controls that later.

Learn 2 · How testing tools find a section

data-testid is a custom HTML data attribute. A tester can find an element using its exact identifier string without relying on the text the visitor sees.

Source with a different example
<section data-testid="hours-box">
  <h2>Open Hours</h2>
  <p>See our schedule.</p>
</section>

A test seeking hours-box could identify this section.

Visible webpage

Open Hours

See our schedule.

The identifier stays in the code. It does not print itself on the page.

Exact-match rule: changing spelling, capitalization or a hyphen can make a test miss a section. CSS controls how the sections will look in a later lesson.
