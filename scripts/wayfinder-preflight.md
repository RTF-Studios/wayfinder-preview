# Wayfinder release preflight

Run all of these checks on each finished course/DayID.html before marking it ready:
- Reopen fresh and inspect the JavaScript console for startup exceptions.
- Confirm Warm-Up, both Questions, Temperature, and Lab copy/submit buttons actually work and reset on edits.
- Confirm all four checklist boxes are required to unlock the Labs.
- Confirm four text-only RTF notes and actual approved comic + text skit are visible.
- Confirm correct image files load and no placeholder remains.
- Confirm the complete prefilled school Form identifiers and authorized Collector receipt.
- Confirm the Control Station row, Order and Show values propagate to the public feed and course library.

Static source or JavaScript syntax alone never counts as a live browser pass.
