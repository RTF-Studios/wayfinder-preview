# Lesson artwork assets

This folder holds approved, optimized student lesson artwork (for example the four universal monster illustration sheets). Keep the canonical original images in Personal Drive; publish stable GitHub Pages image paths here. Full-size student-readable sheets, white background and light dividers support Windows + Shift + S snipping. Do not substitute the older Monsters Can Be Kind art library. Do not expose a lesson asset link before its image file exists and has passed an actual load check.
