# RTF artwork

Canonical location for optimized reusable RTF character art (Pixel, Onion.exe, Tank, Forge and other approved illustrations).

Existing binary images still in `assets/` are referenced by live lessons and cannot yet be relocated using the current text-only file writer. Move them here with binary-safe Git support, and update all `src` references before removing old copies. Do not recreate or alter approved artwork.
