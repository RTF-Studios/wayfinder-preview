LEARN — GAME DESIGN STUDIO KNOWLEDGE

Today is a guided first project, not a test of memorized block names. A SPRITE is a game object. An EVENT begins instructions after an action, such as pressing the green flag or clicking a sprite. A VARIABLE stores a changeable value such as score. A CONDITION checks whether a rule is true, such as whether the score is at least five. A prototype proves the core interaction works before the designer adds elaborate art. Use one sprite and one action. Keep the controls clear, give instant visual feedback, and reset the game consistently.

REAL-WORLD EXAMPLE / VISIBLE SPECIMEN

MICRO-GAME: 'Click the Star Five Times.' At start: score=0; sprite says 'Click me five times'. On click: score increases by 1; sprite changes appearance or briefly says '+1'; when score reaches 5, show 'You win!' and stop scoring. Pseudocode: WHEN green flag clicked → SET score to 0 → SAY instructions. WHEN sprite clicked → IF score < 5 THEN CHANGE score by 1 → IF score > 4 SAY 'You win!' END.

EXTRA HELP — OPEN WHEN NEEDED

Blocks to find: Events (when green flag clicked; when this sprite clicked), Variables (make variable; set score to 0; change score by 1), Control (if then), Operators (<, > and = use comparison blocks; to test at least five, compare score > 4), Looks (say). Build and test ONE event script at a time. If clicking does nothing, confirm the blocks are attached to the sprite, not the Stage. If it wins immediately, reset score and inspect the comparison. If the score keeps growing, add a condition that only allows clicks before winning.
