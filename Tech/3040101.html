02 · Learn together

Group Learn

Decomposition means dividing a big problem into small steps. A flowchart uses START and END, arrows for order, action boxes for work, and diamond questions for decisions. A game needs a player, controls, hazards and an outcome. We will build them one at a time.

Read the sequence

START → action → decision? → next action or retry → END

In a flowchart, arrows show order. A decision changes what happens next. Repeated actions need a purpose.

Discuss: What should happen first? What test would reveal a mistake? Predict before looking at a solution.

03 · Try together

Group Practice

Draw a START → pack backpack → check bag → leave home flowchart, including one yes/no choice.

  1. Identify one action, one decision and the start.
  2. Predict a specific outcome when a condition is true and when false.
  3. Explain how you would verify that the sequence works.
04 · Independent mastery

Registered Mastery Question

Given a flowchart of a simple arrival routine, identify two subproblems and explain the order and repeated patterns.

Independent scenario

A student enters school, checks for an ID badge, visits the office if it is missing, finds the classroom, waits if the door is closed, then enters. A flowchart shows the two yes/no questions.

YES at the final door decision means enter classroom and end. Follow both NO paths before answering.

05 · Build

Perform — Break an Escape Game into Steps

Continue the SAME editable Turkey Escape project in TurboWarp. Save the .sb3 file using the approved school procedure.

  1. Open TurboWarp and locate Stage, Code, Costumes and the green flag.
  2. Use a simple built-in sprite or draw an oval turkey; avoid spending the lesson on artwork.
  3. Make when green flag clicked → go to x:0 y:-70 so the turkey starts in a known spot.
  4. Make when right arrow key pressed → change x by 10. Predict what will happen and test one press.
  5. Save the editable .sb3 in the approved school location. Keep the project for Day 2.
Extra Help — tools and blocks

Select your sprite first. In the Code tab, Events, Motion, Control and Variables categories contain the blocks. Check the Stage after one small change. Do not remove code that already works.

Extra Help — save and restore
