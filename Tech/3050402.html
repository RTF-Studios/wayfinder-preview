Tool reminder and teacher demonstration

In code, STATE stores whether a special condition is active; an EVENT or CONDITION changes state; visual feedback tells the player what happened. The class examines a worked shield recipe: make shieldActive and shieldReady for all sprites, set both to 0/1 respectively on green flag. On Player: when [s] key pressed, if shieldReady=1 then {set shieldReady=0; set shieldActive=1; say 'Shield ON' for 1 sec; wait 3 seconds; set shieldActive=0; wait 7 seconds; set shieldReady=1}. In FallingObject collision code, only deduct a life when shieldActive=0, and still mark hitThisFall to avoid repeat collision. Teacher-supported alternate recipe A: make gameSpeed start 5, increase by 1 at milestones of five SAFE dodges and cap at 10; use gameSpeed in downward y-change instead of fixed 5. Alternate recipe B: clone/duplicate a falling obstacle as an Enemy, independent randomized spawn and a different fair collision rule; do not count enemy misses as normal dodge points. Use ONE feature only; students choose the story-relevant recipe. Teacher verifies code recipe and demonstrations before guide build; this is specification, not automatically code QA.

Shield test: S activates protection for four seconds (the one-second message plus three-second wait), then seven seconds of recharge. One contact marks that fall even when protected, so it cannot award a dodge point. Pressing S during recharge has no effect. Test life loss with shield on/off, repeated key presses and green-flag reset.

      end
    end
    wait (0.03) seconds
  end
  if <(hitThisFall) = (0)> then
    change [score] by (1)
    set [gameSpeed] to ((5) + ([floor] of ((score) / (5))))
    if <(gameSpeed) > (10)> then
      set [gameSpeed] to (10)
    end
  end
end

Use Operators for subtraction, division and the math dropdown floor. Keep gameSpeed visible as the speed meter and label its meaning in your instructions. Speed starts at 5, becomes 6 after five safe dodges, 7 after ten and stops increasing at 10. Hits do not add points. Test score 4→5, 9→10, the cap and restart.
