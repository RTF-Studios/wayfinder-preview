Five-minute warm-up · Mini-Learn

Where do your eyes go?

On a readable book page, the title is easy to find, the story text has comfortable space, and the illustration area does not cover the words. Alignment means lining elements up. Margins are the breathing room around content. Proximity means keeping related information close together.

Required Perform

Build one readable story page

Use the same editable Slides storybook you worked in yesterday. Find it through your teacher-assigned Google Classroom work. Do not submit a different file or create a disconnected replacement.

  1. Open the existing Slides project. Confirm your title slide is present. If you cannot access the assigned file, tell the teacher before continuing.
  2. Add a story page. Use the + New slide control. To keep consistent typography, use the same font family as your title slide.
  3. Insert a short paragraph. Select Insert → Text box, drag on the slide, and type 1–3 story sentences. Select the box border to move the whole box. Pull its corner handles to resize, keeping the words readable.
  4. Make an illustration space. Select Insert → Shape → Shapes and choose a rectangle. Drag it into an empty part of the slide. Label it “Illustration goes here.” If it covers words, move or resize it. Use Arrange → Order if an object must sit behind another.
  5. Check the layout. Compare to Example B. Keep the paragraph separate from the rectangle, align edges, leave margins, and make the page title easy to find. Keep both slides in the teacher-assigned file.

Quick tool reference

Text: Insert → Text box → drag → type.

Move: Click the box border, drag into position.

Resize: Drag a selection handle.

Picture space: Insert → Shape → Rectangle.

Undo: Ctrl+Z. Keep your copy: work in the existing assigned file.
